# dynamic-php-html-website

This repository contains the course project "Dynamic PHP & HTML Website" built as part of the Script Programming coursework. The multi‑page website implements session management, navigation menus, contact forms that collect and display user input, and an interactive image slideshow with JavaScript and CSS enhancements.

## Project Link

The full project is hosted on Replit: [PowerfulClutteredObjectdatabase](https://replit.com/@jlb282/PowerfulClutteredObjectdatabase?v=1)

## Features

- Session management and login state using PHP sessions.
- Dynamic navigation menu built with PHP arrays.
- Contact forms that process user input and display results.
- Interactive image slideshow implemented with HTML, CSS, and JavaScript.
- Organized code structure with separate PHP files for assignments and the final project.

## Usage

Clone this repository to see this README; the source code is hosted on Replit via the link above.
